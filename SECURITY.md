# Security

Threat model: hostile apps/packages, malformed input, compromised update channel, filesystem corruption, sync interception, excessive resource consumption and accidental disk overwrite. Default deny capabilities; enforce host process isolation initially, later kernel boundary. No privileged operations in P0. No mandatory network, account or telemetry. Secrets in host secure store; never commit keys. Signed packages and manifests, verified updates, rollback protection and recovery before distribution. Bound all input and resource usage. Audit dependencies and licenses; fuzz parsers; document every unsafe invariant. Never write raw disks on a host without explicit authorization and verified backup/recovery. Report vulnerabilities privately to the repository owner until a dedicated reporting channel is configured.
